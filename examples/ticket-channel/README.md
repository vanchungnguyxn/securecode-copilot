# TicketChannel — kênh đặt vé sự kiện (web bình thường)

Trang xem sự kiện + form đặt vé. Không cố ý cài lỗ hổng, cũng không gắn lớp bảo mật nâng cao — chỉ làm cho chạy được.

```powershell
pip install -r requirements.txt
python app.py
```
